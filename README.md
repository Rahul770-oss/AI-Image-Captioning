# AI-Image-Captioning

Vision-Language Model using Salesforce BLIP. Generates natural captions for any image.

## Demo
Model: Salesforce/blip-image-captioning-base
Input: Any image URL / local image
Output: "a woman sitting on the beach with a dog"

## How to run
pip install -r requirements.txt
python app.py

## Tech Stack
Python, Transformers, PyTorch, BLIP, PIL

## Use case
Accessibility tool for visually impaired, auto alt-text generation
